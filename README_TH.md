# TACTICAL ARENA — เว็บเกม FPS ต้นแบบ

โปรเจกต์นี้เป็นเกมยิงมุมมองบุคคลที่หนึ่งบนเว็บที่พัฒนาขึ้นใหม่ ได้แรงบันดาลใจจากเกมแนว Point Blank แต่ไม่ได้ใช้โค้ด แผนที่ โมเดล เสียง หรือเครื่องหมายการค้าของเกมต้นฉบับ

## วิธีเปิดบนคอมพิวเตอร์
1. ติดตั้ง Node.js รุ่น LTS
2. แตกไฟล์ ZIP แล้วเปิดโฟลเดอร์นี้ใน Terminal
3. รัน `npm install`
4. รัน `npm start`
5. เปิด `http://localhost:3000`

## วิธีเปิดออนไลน์
ต้องนำโปรเจกต์ขึ้นบริการที่รองรับ Node.js และ WebSocket (เช่น Render หรือ Railway) ไม่ใช่ GitHub Pages แบบเว็บ static อย่างเดียว จากนั้นกำหนด Environment Variables:
- `ADMIN_USER` = `admin`
- `ADMIN_PASS` = รหัสแอดมินที่ต้องการ (แนะนำให้เปลี่ยนจากรหัสเริ่มต้น)

## สิ่งที่มีในรุ่นเริ่มต้น
- ล็อกอินด้วยชื่อผู้เล่นและป้องกันชื่อซ้ำในขณะที่ออนไลน์
- ฉาก 3D และการเคลื่อนที่ FPS
- ผู้เล่นออนไลน์เห็นตำแหน่งกันแบบเรียลไทม์
- ยิงผู้เล่นอื่น ระบบ HP, Kill และ Death แบบพื้นฐาน
- แผงแอดมิน: แจก Rifle, ฮีล, วาร์ปไปหาผู้เล่น, เตะ และแบน
- เพิ่มรายการอาวุธแบบพื้นฐาน

## ข้อจำกัดที่ควรรู้
นี่คือรุ่นต้นแบบสำหรับต่อยอด ยังไม่ใช่เกมระดับ PB Mobile: ยังไม่มีระบบฐานข้อมูลถาวร, ระบบห้อง/ทีม/แมตช์เต็มรูปแบบ, ระบบป้องกันโกงที่แข็งแรง, แอนิเมชัน/โมเดลปืนจริง, เสียง, สกินที่แสดงผลจริง หรือระบบชำระเงิน การแบนในรุ่นนี้เก็บในหน่วยความจำและจะหายเมื่อรีสตาร์ตเซิร์ฟเวอร์

## ความปลอดภัย
ระบบชื่ออย่างเดียวเหมาะกับเดโมเท่านั้น ผู้เล่นอาจแอบอ้างชื่อคนอื่นได้ในอนาคต ควรเพิ่มระบบยืนยันตัวตน/ผูกบัญชีและฐานข้อมูลก่อนเปิดสาธารณะ อย่าใส่รหัสแอดมินไว้ในไฟล์หน้าเว็บ
